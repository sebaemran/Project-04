Personal Portfolio — Project 04
About the Project
This project is a personal portfolio website created to showcase my skills, projects, interests, and contact information.

The website is built from scratch using HTML5, CSS3, and JavaScript, without using frameworks or UI libraries.

Features
About Me: A brief introduction and profile photo.
Skills: A grid displaying my technical skills.
Projects: A showcase of Projects 00, 01, 02, and 03, with links to their GitHub repositories.
Hobbies: A section highlighting my personal interests.
Contact Form: A form for visitors to enter their name, email, and message.
Theme Switcher: An interactive button that switches between light and dark themes.
Responsive Design: A layout that adapts to desktop and mobile screens.

Technologies Used
HTML5
CSS3
JavaScript ES6+
Git and GitHub

How to Run
Clone or download the repository.
Open the project folder in Visual Studio Code.
Open index.html in a web browser.
Explore the portfolio and test the theme switcher.

What I Learned
Through this project, I practiced building a complete web page, organizing content with semantic HTML, styling layouts with CSS Flexbox and Grid, creating responsive designs with media queries, and using JavaScript to manipulate the DOM and handle user events.
